# Low-Res Meme Cat

「低清奶茶小猫」是一套真实猫图二创风格表情包：微信群聊梗图、低画质、JPEG 糊图、精神状态抽象。

## Structure

```text
low-res-meme-cat/
├── docs/
│   ├── design.md
│   ├── prompt.md
│   └── scenes.md
└── stickers/
    └── wip/
```

先读 `docs/design.md` 确认边界，再从 `docs/scenes.md` 挑一句聊天场景，套入 `docs/prompt.md` 生成。最终公开图放进 `stickers/`。
