# 微信表情包横幅 Banner 提示词

## 微信规格

- 输出：`750 x 400` 像素。
- 格式：JPG 或 PNG，必须是不透明背景。
- 图片里不要出现任何文字，包括中文、英文、数字、logo、水印。
- 背景不能是白色或透明，要和微信白/浅灰底色有明显区分。
- 画面必须和表情包主题有关，内容要丰富、有一点故事性。
- 所有元素保持原比例，不要拉伸、压扁或变形。

## 生成提示词

生成一张微信表情包横幅 banner，尺寸 750 x 400，PNG 或 JPG，不透明背景，无任何文字。

主题是「像素奶茶小猫」。整体是明亮、热情、卡通一点的复古像素风，不是现代高清插画，不是 3D，不是真实猫照片。画面使用硬边像素、有限色盘、清晰深色像素描边，像 tiny pixel emoji / Japanese deco-mail pixel sticker / Tamagotchi-style sprite。

主角是一只浅奶茶小鹿色像素小猫，主毛色接近 #F5DDC4，高光接近 #FFF2E2，阴影接近 #E2C6AA。圆头、小三角耳、深棕或黑色点眼、粉色小鼻子、短爪、简单尾巴，身体是纯色块，不画毛发纹理。不要画成纯白猫、冷白猫、橘猫或深金色猫。

主视觉：画面中间是一只浅奶茶小鹿色像素小猫正在喝珍珠奶茶，双爪抱着浅焦糖色奶茶杯，绿色或薄荷色吸管靠近嘴边，表情开心、满足、呆萌。奶茶杯要清楚，但不能比小猫更抢眼。

故事性：周围可以安排 2 到 3 个小场景作为配角，例如一只小猫抱粉色爱心、一只小猫抱浅蓝小鱼、一只小猫躺在奶茶杯或牛奶杯里。配角要比主角小，不要抢主视觉。

背景：暖色调、明亮、活泼，使用蜜桃橙、奶油黄、浅杏色、珊瑚粉、焦糖奶茶色、暖米色，少量薄荷绿点缀。可以是像素奶茶店小角落或暖色像素 UI 面板，有小星星、小爱心、珍珠、奶茶杯、小爪印等像素装饰。背景要丰富但不能太复杂，不要使用白色背景，不要透明背景。

避免：任何文字、白色背景、透明背景、正方形硬边框、真实猫、3D、毛绒质感、渐变、真实阴影、过度复杂背景、过度饱和、拉伸变形、压扁变形、水印。
