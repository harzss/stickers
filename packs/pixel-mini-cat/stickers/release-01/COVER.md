# 微信表情包封面图提示词

## 微信规格

- 输出：`240 x 240` 像素。
- 格式：PNG。
- 必须是透明背景，不要白色背景。
- 选择最具辨识度的表情形象，建议正面半身像或全身像，不要只用头部。
- 形象不能有白色描边，边缘要干净，避免脏边和多余锯齿。
- 不要出现文字。
- 画面尽量简洁，不要加入复杂装饰元素。
- 主体布局要饱满，不要留太多空白。

## 生成提示词

生成一张微信表情包封面图，尺寸 240 x 240，PNG，透明背景，无任何文字。

主体只放一只最具辨识度的浅奶茶小鹿色像素小猫，正面半身或全身像。小猫正在喝珍珠奶茶，双爪抱着一杯浅焦糖色奶茶，绿色或薄荷色吸管靠近嘴边。小猫要占画面主体，布局饱满但不要贴边。

小猫主毛色接近 #F5DDC4，高光接近 #FFF2E2，阴影接近 #E2C6AA。圆头、小三角耳、深棕或黑色点眼、粉色小鼻子、短爪、简单尾巴，身体是纯色块，不画毛发纹理。轮廓使用深棕或黑色像素描边，不要白色描边，不要白边，不要发光外描边。

整体风格是清晰、可爱、明亮的复古像素风，像 tiny pixel emoji / Tamagotchi-style sprite。画面只保留小猫和奶茶杯，不加背景装饰、不加星星、不加爱心、不加标题栏。透明区域必须只在角色外部，眼睛、鼻子、嘴巴、轮廓和奶茶杯都必须是不透明实心像素。

避免：文字、白色背景、非透明背景、白色描边、正方形边框、复杂装饰、多只猫、只画猫头、真实猫、3D、毛绒质感、渐变、真实阴影、脏透明边、拉伸变形。
