# 微信表情包图标提示词

## 微信规格

- 输出：`50 x 50` 像素。
- 格式：PNG。
- 必须是透明背景，不要白色背景。
- 选最具辨识度、最清晰的图片，建议只用表情角色头部正面图像。
- 画面尽量简洁，避免加入装饰元素。
- 形象不能有白色描边，边缘要干净，避免脏边和多余锯齿。
- 不要出现正方形边框，避免主体出现生硬直角边缘。
- 主体布局要饱满，不要留太多空白。

## 生成提示词

生成一张微信表情包图标，尺寸 50 x 50，PNG，透明背景，无任何文字。

主体只放一只浅奶茶小鹿色像素小猫的正面头部或头部加一点上半身。小猫要居中、清晰、饱满，小尺寸下能一眼看出是这套表情包的主角。可以让小猫嘴边有一根很小的绿色或薄荷色吸管作为“奶茶小猫”识别点，但不要画完整奶茶杯，避免小尺寸太乱。

小猫主毛色接近 #F5DDC4，高光接近 #FFF2E2，阴影接近 #E2C6AA。圆头、小三角耳、深棕或黑色点眼、粉色小鼻子，脸侧各 1 个小毛尖。轮廓使用深棕或黑色像素描边，不要白色描边，不要白边，不要发光外描边。

整体风格是极简清晰的微型像素头像。不要背景、不要边框、不要装饰、不要星星、不要爱心、不要文字。透明区域只在角色外部，眼睛、鼻子、嘴巴和轮廓必须是不透明实心像素。

避免：文字、白色背景、非透明背景、白色描边、正方形边框、复杂装饰、多只猫、完整场景、真实猫、3D、毛绒质感、渐变、真实阴影、脏透明边、拉伸变形。
